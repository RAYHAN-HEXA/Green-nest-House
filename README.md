README File
🍃 GreenNest – Indoor Plant Care & Store
GreenNest is an elegant Single-Page Application (SPA) designed for plant enthusiasts to explore indoor plants, access care guides, and book expert consultations. The project focuses on a minimalist nature-inspired UI and seamless user authentication.

🛠 Technologies Used
Frontend: React.js (v18+)

Routing: React Router DOM

Styling: Tailwind CSS & DaisyUI

Backend/Auth: Firebase

Animations: Framer Motion & Swiper.js

✨ Core Features
Secure Authentication: Email/Password and Google Social Login.

Protected Routes: Restricted access to Plant Details and User Profile pages.

Dynamic Catalog: Plant data fetched dynamically from JSON files.

Consultation Booking: Functional booking form with real-time toast notifications.

Profile Management: Ability to update user display name and photo URL.

Password Security: Strong validation (Uppercase, Lowercase, 6+ characters).
